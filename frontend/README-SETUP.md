# The Gladiators School and College - SEO Frontend

## 1. Copy the logo
Copy:
src/assets/logo.jpeg

to:
public/logo.jpeg

## 2. Environment
Create a frontend `.env` file:

VITE_API_BASE_URL=https://the-gladiator-college.vercel.app

This must point to your deployed admission backend.

## 3. Install
npm install

## 4. Run locally
npm run dev

## 5. Build
npm run build

## 6. Routes
/
/about
/programs
/admissions
/contact

## 7. Important
The phone number, email, exact street address, social links and other official organization details should only be added to SEO structured data after they are confirmed as official.
